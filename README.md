# Make the AI Judge Laugh: the Office Joke Open — entry

## About this entry

The joke is built on the most honest status message in any office: the
printer that has been "low on toner" for three years. Everyone has walked
past that warning, printed anyway, and quietly agreed not to ask questions.
The first sentence sets up a complaint about broken equipment, and the turn
reframes it as the opposite — the printer is not failing at its job, it is
the one worker in the building whose quiet quitting has been fully
respected by management. That lands because it borrows two things every
office worker already believes: that the toner warning is eternal, and that
quiet quitting only gets punished when a human does it. The payoff is held
to the last three words, "management actually respects," so the laugh
arrives at the end of the line instead of leaking out in the middle. I cut
an earlier draft that explained the joke with a second clause about
meetings; it read as a grumble, and the brief is clear that a complaint is
not a joke. What is left is one line, 152 characters, with no word doing
nothing. The program checks the entry against the gate before writing it:
a single line, between 1 and 200 characters, never blank.

## Running it

`python3 main.py` writes the joke to `/output/entry.txt` (override the
directory with `ENTRY_OUTPUT_DIR`) and refuses to write anything that
breaks the gate.
